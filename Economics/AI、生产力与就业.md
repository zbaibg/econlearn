# AI、生产力与就业

AI首先可以视为[[生产率]]或技术水平 $A$ 的提高：

$$Y=F(K,L,R;A)$$

在其他条件相同时，$A\uparrow$ 可以提高产出 $Y$。

但AI还可能削弱传统的耦合：

```text
更多产出 → 需要更多人类劳动
```

因此可能同时出现：

$$Y\uparrow\uparrow,\qquad \text{就业}\downarrow$$

## 分配问题

现代社会常见的分配链条是：

```text
劳动 → 工资 → 购买力 → 消费
```

如果生产越来越不依赖人类劳动，而收入分配仍然高度依赖劳动，就可能出现：

```text
AI提高生产能力
→ 部分劳动被替代
→ 部分劳动收入下降
→ 购买力下降
→ 有效需求受到影响
```

因此AI问题最终不仅是“能生产多少”，也是“新增产出的索取权如何分配”。
