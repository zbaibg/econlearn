# 分配、收入与需求

生产出 $Y$ 之后，还需要决定产出的索取权如何分配：

$$Y\rightarrow\{y_1,y_2,\ldots,y_N\}$$

[[收入]]可以从实物角度近似理解为获得社会商品与服务的索取能力。

## 有效需求

$$\text{有效需求}=\text{想要}+\text{支付能力}$$

因此“人需要某种东西”和“市场表现出足够需求”不是同一件事。

现代制度下的重要链条是：

```text
劳动 → 工资 → 购买力 → 消费需求
```

这使[[就业]]同时具有生产和分配意义。
